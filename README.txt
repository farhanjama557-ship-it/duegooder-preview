DUEGOODER VERCEL PREVIEW

This is a UI-only preview. It uses simulated sample data so it can deploy as a static Vercel site with no backend.

DEPLOY FROM MAC:
1. Unzip the folder.
2. Open Terminal and cd into it.
3. Run: npx vercel
4. Follow the login prompts.
5. When asked to set up and deploy, answer Y / accept defaults.

DELETE LATER:
Delete the project from your Vercel dashboard when finished.
