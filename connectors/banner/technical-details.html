Detection Method

Banner detection is designed to combine public URL patterns, page content analysis, HTML fingerprints and known Banner endpoints to identify Banner 9 self-service registration systems. Multiple independent signals are required before a domain is classified.

Detection Signals

  • StudentRegistrationSsb
  • /ssb/term/termSelection
  • /ssb/searchResults
  • /ssb/sectionDetail
  • Banner-specific HTML elements
  • Known Banner route patterns

Known Banner Endpoints

/StudentRegistrationSsb/ssb/term/termSelectionPublic term selection page
/StudentRegistrationSsb/ssb/classSearch/classSearchClass search entry point
/StudentRegistrationSsb/ssb/searchResults/searchResultsSection results (JSON)
/StudentRegistrationSsb/ssb/searchResults/getSectionDetailSingle section detail
/StudentRegistrationSsb/ssb/classSearch/get_subjectSubject list for a term
Detection limitsDetection uses public pages only. It can fail on custom implementations, blocked or rate-limited requests, registration systems hidden behind login, and institution-specific routing.

Detection Process

1Fetch homepage / registration page
2Analyze URL structure and content
3Match against Banner fingerprints
4Assign confidence score
5Validate multiple signals
6Cache result (24h)

Rate Limits

1 request per second
5 concurrent requests
10s timeout
Respects robots.txt
